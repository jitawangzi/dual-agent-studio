## 使用边界

验证结论仍需人工判断；“本次未复现”不代表误报或已修复。不填写复现命令时只能提供源码证据和建议步骤，模型建议的新命令不会自动执行。源码指纹在启动验证、修复及验证执行前后检查，不随页面轮询持续扫描。历史验证对应当时源码，修复后应重新审核。

详细操作见 [独立验证发现与分诊筛选](version-2.3.md)。
