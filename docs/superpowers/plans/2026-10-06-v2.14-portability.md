# 2.14 证据导出与存储维护 Implementation Plan

> **For agentic workers:** 逐任务执行，默认单 Agent。任何向外部账户上传、发送报告或删除历史的行为都不属于本版授权。

**Goal:** 让用户能把审核证据带给其他人/模型，诊断失败并管理历史列表，同时保留可恢复的本地原始数据。

**Architecture:** 生成带哈希清单的只读JSON/HTML报告，显式选择附件与脱敏；归档采用显示层索引，不移动或删除证据文件。导入只进入外部报告查看器，不能恢复执行权。

**Tech Stack:** Node内置fs/path/crypto、HTTP下载、原生HTML；不引入ZIP/PDF运行时库。

**Spec:** [总体设计](../specs/2026-10-06-next-versions.md)。依赖2.10schema/恢复、2.11调用元信息，以及2.13决策事项。

## Global Constraints

Windows / PowerShell 7 / Node.js 18+；后端零新增npm运行时依赖；原证据保留；不自动上传、发消息或删除；导入审批不构成当前执行授权；哈希校验不是数字签名。

## Task 1：可预览的证据包

**Files:** 新建 `engine/evidence-export.js`、`tests/evidence-export.tests.js`；扩展schema以识别export格式（不混入运行记录kind）。

**Interfaces:**

```js
planExport(store,{auditId,includeArtifacts:false,redactPaths:true});
// {version,recordRefs,artifactRefs,omissions,warnings,estimatedBytes}
buildExport(store,{version,auditId,includeArtifacts,redactPaths});
// {formatVersion:1,generatedAt,records,artifacts,manifest,limitations}
// manifest: [{name,sha256,bytes}]；只校验包内字节，不能证明内容真实或作者身份
resolveExportArtifact(recordDir,name); // 校验白名单与realpath边界，返回可读绝对路径
```

manifest只覆盖载荷条目，不包含自身：结构化记录按确定键顺序序列化成`records.json`字节，附件名为`artifacts/<kind>/<recordId>/<basename>`。导入使用相同确定性序列化规则验证；重复载荷名或未知条目拒绝，不能只验证声明的sha256字段是否长得像哈希。

- [x] 闭包包含审核组、关联修复、方案及决策事项的必要来源引用；循环引用用kind+id去重，缺失引用列出omissions，不假装完整。
- [x] 默认只包含结构化摘要，不含原始prompt、模型全文、命令输出或目标仓库源码。附件由用户逐类选择，预览显示可能包含路径/源码/敏感信息。
- [x] 默认路径替换为稳定占位符；用户可添加明文遮盖规则。自动脱敏只声明处理了哪些模式，不保证识别所有秘密，下载前允许查看样本。
- [x] 脱敏副本不回写原记录；manifest哈希针对导出后的字节。未脱敏原文哈希可作为独立来源声明，但不能冒充与脱敏字节一致。
- [x] artifact只允许已有record目录下的白名单文件；拒绝 `../`、绝对路径、符号链接越界、重复文件名覆盖。用realpath校验，不能只看字符串前缀。
- [x] 默认限制报告JSON 5MiB、选择附件后总量20MiB；超限明确列出待排除项并要求缩小选择，不静默截断证据。限制作为配置常量并测试边界。
- [x] 预览和生成之间任一来源变化返回 EXPORT_VERSION_CONFLICT；坏记录不阻止预览列出错误，但不生成声称完整的证据包。

测试示例：

```js
const before=fs.readFileSync(store.file('audits',auditId),'utf8');
const bundle=buildExport(store,options);
assert.equal(fs.readFileSync(store.file('audits',auditId),'utf8'),before);
assert.throws(()=>resolveExportArtifact(recordDir,'../secrets.txt'),/INVALID_ARTIFACT/);
assert.ok(bundle.limitations.includes('Historical evidence; not current execution authorization'));
```

## Task 2：离线报告与只读导入

**Files:** 新建 `engine/evidence-report.js`、`public/report-viewer.js`、对应tests；增加server下载/导入端点。

**Interfaces:** `renderReport(bundle) -> string`；`validateImportedBundle(bundle) -> {ok,errors,manifestValid}`。

- [x] HTML静态输出所有模型文本转义，不运行模型内容中的脚本、事件处理器、CSS或外部图片；加CSP，链接只生成经过校验的包内目标。
- [x] 两个下载格式：JSON证据包、静态HTML报告。第一版不提供ZIP/PDF；用户可打印HTML，避免引入依赖。
- [x] 导入先校验formatVersion、体积、条目数、字段类型、manifest；JSON中的路径/ID只作数据，不据此写任意文件。
- [x] 外部包独立存于数据根imports下的新UUID目录；绝不与本地同名record合并，不执行里面的命令，不调用RunStore.approvePlan或resume。
- [x] 查看器明确“外部历史报告，当前源码有效性未知”；即便里面是APPROVED，也没有启动/修复按钮。将其用于新任务须重新选择本地workspace、方案和审批。
- [x] 测试 `<script>`、`onerror`、javascript链接、伪造大数组、未来formatVersion、校验和不一致、与现有UUID碰撞。
- [x] 下载采用正确Content-Type、attachment文件名、nosniff；不让完整本地路径出现在默认下载文件名中。

## Task 3：整组逻辑归档与恢复

**Files:** 新建 `engine/record-archive.js`、`tests/record-archive.tests.js`；修改历史列表API/UI；保留RunStore默认业务读取行为。

**Interfaces:**

```js
previewArchive(store,{auditId}); // {version,recordRefs,blockers}
applyArchive(store,{version,auditId,note}); // 写 archives/index.json 中的组事件
restoreArchive(store,{archiveId,version}); // 幂等恢复显示
```

- [x] 按关联组预览，显示所有将隐藏的审核、补审、修复和决策事项；被组外活动记录引用时拒绝或扩展成完整组供用户重新确认。
- [x] 任一活动任务、未退出的进程、正在导出/迁移的写操作都阻止归档。版本冲突返回409。
- [x] 只在历史列表默认筛选中隐藏；`RunStore.read/list` 的业务证据查询不因归档丢失记录，避免破坏闭环和问题台账。
- [x] 页面提供“显示归档”和恢复；同一归档请求重复提交不生成重复组或丢失恢复入口。
- [x] 明示“逻辑归档不释放磁盘空间”。本版不提供物理删除，磁盘回收需后续有备份校验的独立设计。
- [x] 测试归档后附件可读、原人工验收不被修改、恢复保持原引用、正在运行时拒绝、关联组并发预览冲突。

## Task 4：诊断包与存储概览

**Files:** 新建 `engine/diagnostics.js`、`public/maintenance.js`；扩展2.10维护页；新增HTTP/UI测试及版本文档。

- [x] 显示记录数量、附件字节、坏记录/未来版本数、逻辑归档数；扫描分批执行并支持取消，不阻塞主页面长时间无反馈。
- [x] 诊断包默认包含应用/Node/PowerShell/CLI版本、错误码、最近调用的脱敏元信息、迁移版本和残留进程诊断；不读取环境变量全集、token文件、Cookie或完整工程源码。
- [x] 显示缺少哪些信息，未知Provider版本不触发真实模型探测。用户可预览并单独下载，不自动发给任何服务。
- [x] 浏览器验证：导出预览→选择附件→下载JSON/HTML→离线打开→显示历史限制→逻辑归档/恢复→诊断包预览。
- [x] 全量npm test；恶意内容HTML检查；确认包内相对链接与哈希可验证；更新2.14文档和交接记录。

**版本退出条件:** 证据可带走且边界清楚，旧数据未被导出/归档流程修改，导入不能获得执行权，用户能自行下载诊断信息。不包含自动备份上云或磁盘清理。
