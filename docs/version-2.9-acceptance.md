## 自动化与独立复核

`npm test` 全量回归通过：108 项 Node 测试全部通过，服务器集成、前端契约、PowerShell Provider 适配与编排测试通过。新增测试涵盖补审合并、源码与证据过期、验收版本冲突、说明必填、幂等提交、真实命令执行、暂缓原因、停止与重启恢复。

独立只读复核发现的问题均先补充失败用例再修复，并经过针对性复核：

- 成功的同级补审不能掩盖其他补审新增的覆盖缺口。
- 同一问题按审核员实际发现时间合并，旧修复不能覆盖新发现。
- 残留验收测试进程阻止新操作，原审核操作也检查相关 PID。
- 关闭结论必须逐个 Bug 匹配当前源码；修复循环的源码变化会重新触发旧 Bug 的独立验证。

源码及证据版本在服务端核验。浏览器中正在编辑的验收说明也绑定其证据版本，刷新得到新证据后不能直接提交旧说明。
